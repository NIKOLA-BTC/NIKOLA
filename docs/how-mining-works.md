# How Mining Works

Bitcoin mining is the process of using computational power to validate transactions and secure the Bitcoin blockchain.

Mining machines continuously perform cryptographic calculations to compete for Bitcoin block rewards.

When a valid block is produced, Bitcoin rewards are distributed according to contributed hashrate.

---

# The Role of Hashrate

Hashrate represents computational power contributed to the Bitcoin network.

Higher hashrate increases participation in Bitcoin block production.
