# Hashrate Explanation

Hashrate measures the computational power used in Bitcoin mining.

It represents how many cryptographic calculations are performed every second.

---

# Common Units

| Unit | Meaning |
|---|---|
| KH/s | Thousand hashes per second |
| MH/s | Million hashes per second |
| GH/s | Billion hashes per second |
| TH/s | Trillion hashes per second |
| PH/s | Quadrillion hashes per second |
| EH/s | Quintillion hashes per second |

---

# TH/s Explained

NIKOLA plans are based on TH/s (Terahash per second).

1 TH/s represents one trillion hash calculations every second.

Higher hashrate contributes more computational work to the Bitcoin network.
