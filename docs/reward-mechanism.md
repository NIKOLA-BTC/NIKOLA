# Reward Mechanism

Bitcoin mining rewards are generated through block production on the Bitcoin network.

Mining infrastructure contributes computational power to secure the blockchain and participate in block generation.

---

# User Reward Allocation

User rewards are calculated according to:

- Purchased hashrate amount
- Mining uptime
- Bitcoin network difficulty
- Block production conditions

---

# Full Reward Ownership

Users retain 100% of mining rewards generated during the contract period.

NIKOLA does not charge:
- Commission
- Electricity fees
- Service fees
